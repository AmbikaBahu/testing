OUR FINANCES V1

Upload the four web files (index.html, manifest.webmanifest, icon.svg, sw.js) to the root of a GitHub repository and enable GitHub Pages from the main branch root. Open the published HTTPS URL on your phone, then use Add to Home Screen / Install App.

Financial data is stored ONLY in this browser/device localStorage. Export JSON backups regularly. CSV export includes expenses, incomes, and settlements and opens in Excel. This is a working initial version; natural-language input, CSV import, and native XLSX export are not included yet.

Do not use a private/incognito browser window for persistent storage.
